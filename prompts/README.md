# prompts/

AI 프롬프트는 코드와 분리해 이 폴더에서 관리한다.

| 파일 | 용도 | 단계 |
|---|---|---|
| `post-draft.md` | 고민 → 익명 게시글 초안 (개인정보 제거, 사실 중심 정리, 질문 보존) | MVP |
| `comment-tone-soft.md` | "부드럽게" 글의 댓글 톤 변환 (입장 강도 유지) | MVP |
| `reflection-qa.md` | 리딩 후 자기이해 문답 | Phase 2 |
| (예정) `reading.md` | 기존 타로 리딩 시스템 프롬프트. 지금은 `api/reading.js` 안에 있음 | 구현 단계에서 이동 |

## 규칙
- 각 파일 맨 위 `version:`을 올리고, 서버는 사용한 버전을 DB(`prompt_version`)에 기록한다. 분쟁이 생기면 어떤 프롬프트로 변환했는지 추적할 수 있어야 한다.
- 사용자 입력은 반드시 `<user_text>` 같은 구분 태그 안에 넣어 전달한다. 프롬프트 본문에 사용자 문장을 그대로 이어 붙이지 않는다 (프롬프트 인젝션 방지).
- 출력은 JSON으로 받고, 서버가 스키마를 검증한다. 검증에 실패하면 사용자에게 AI 출력을 그대로 보여주지 않는다.
- 프롬프트를 바꿀 때는 `prompts/evals/`(예정)의 예시 문장으로 전후 결과를 비교한다. 특히 톤 변환은 "결론이 약해지지 않았는지"를 사람이 확인한다.
- `{{변수}}`는 서버가 채운다.
